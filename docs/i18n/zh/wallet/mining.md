# 内置挖矿

挖矿页面控制完整节点内置的证明与 PoW 流水线。按 `F5` 打开。

![内置矿工控制与已挖区块](../../../assets/wallet/mining.png)

## 启动条件

满足以下条件后才能开始挖矿：

- 节点已同步；
- 至少连接一个经过认证的对等节点；
- 活动地址或配置的奖励地址有效；
- CPU 通过发布版运行所需的硬件检查。

对等节点数量要求可避免节点在孤立的本地视图上误挖。对等节点不会批准
区块，也无法削弱本地证明验证。

## 控制项

选择逻辑 CPU 线程数，然后点击 **开始挖矿**。页面会显示：

- 当前奖励地址；
- 相对于创世目标的难度；
- 当前目标对应的预期哈希工作量；
- 最近十个区块内预期工作量的变化；
- 当前 PoW 数值目标及完整复制按钮；
- 证明和挖矿状态；
- 本机挖出的规范区块。

切换钱包活动地址后，新建模板会使用新的奖励地址；已经在证明或搜索的模板
仍绑定原地址。

## 共享 CPU

证明构建和 nonce 搜索共用一个 CPU 池。钱包不会并行运行两个各自占满全部
核心的挖矿阶段。

本机的发送和归集操作优先。挖矿先让出资源，钱包构建并提交授权，之后自动
继续。

## 停止与退出

点击 **停止挖矿** 后，当前挖矿工作进程会在安全取消点结束。关闭钱包时，
应用也会请求正常停止、将节点数据刷入磁盘，然后退出。

若证明或数据库操作正处于不可中断的边界，关闭可能需要几秒。全屏退出动画
表示工作仍在推进；强制终止进程可能导致下次启动时进行本可避免的数据库
恢复。
