# 合约

使用 **F7 Contracts** 创建策略、充值并与已保存或收到的条款交互。设置位于 F8。

- **Create：**选择可退款付款、保险库、限额钱包、周期预算、定期付款、分期
  解锁或自定义程序。保存条款免费，Call fee limit 限制未来调用手续费。
- **My contracts：**在 Actions、Operations & receipts、Rules 上方选择合约，
  检查活余额、审阅调用并跟踪确认。
- **Open file：**预览收到的合约或调用回执，验证后添加或合并更新，保留自己的
  名称和记录。

日志包括双方已保留的调用。离线且交易体已裁剪后，可能需要另一方提供回执或
更新条款。当前余额来自 State，回执证明过去的调用。
