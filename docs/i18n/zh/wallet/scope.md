# 搜索

搜索页展示规范区块头、当前 Live State 和近期完整数据窗口。按 `F6` 打开。

![规范链浏览界面](../../../assets/wallet/scope.png)

## 查询

搜索框接受：

- bech32m 格式的 `o1…` 地址；
- 区块高度；
- 区块哈希；
- 逻辑交易 ID；
- `slot:<index>`。

查询由本地完整节点完成，不会发送给托管的区块浏览器。

## 区块

规范区块表列出高度、区块年龄、区块 ID、State 级别和数据可用性。
**完整** 标记 18 区块浏览窗口；**区块头** 标记列表中以永久区块头表示的较旧条目。

完整数据保留期间，区块详情包含规范的 212 字节区块头、系统记录和用户
交易。

## 近期交易

近期交易表来自仍保留完整数据的区块。详情中可查看物理页、输入、输出、
所有者、费用和区块内位置。

旧付款不会形成永久的浏览器数据库。它们的规范区块头仍然存在，而保存的
收据提供针对具体交易的纳入证据。

## Live State

查询地址会返回其当前 UTXO；查询槽位会返回当前记录或规范空值。受限
[撤销数据（undo data）](../reference/glossary.md#undo-data)窗口之外，不会重建已经花费的历史占用者。

主页和搜索页的 Live State 图只显示当前占用，不是历史活动热力图。

近期交易 RPC 及 GUI 可用性标记使用 18 区块浏览窗口（目标速度下约 9 分钟）。
节点为同步服务保留 42 个区块体，此服务余量不会扩大 GUI 列表。
