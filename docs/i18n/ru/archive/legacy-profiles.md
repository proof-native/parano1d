# Профили v1 и v1.1

**Исторические правила: до mainnet v2 H210537.** Переход v1 → v1.1 остаётся
на H95125. Форк v2 не переписывает правила прошлых блоков.

| Параметр | Историческое значение |
| --- | --- |
| v1 → v1.1 | H95125 |
| Target interval | 20 s |
| ASERT | 6 blocks / 120 s |
| B25 | m22 / 25 pages |
| B255 | m24 / 255 pages |
| Live-input maximum | 1,020 |
| Subsidy | max(50 / 2^(log_slots − 24), 1) NOID |
| Terminal cap, v1 | 1 MiB |
| Terminal cap, v1.1 shared paths | 1,100,000 bytes |

Число страниц не включает основной coinbase. Дополнительная обязательная
системная запись занимает одну эффективную страницу. Майнер по умолчанию
использовал B25. Первое завершённое построение B25 разрешало B255, если оценка
с коэффициентом четыре укладывалась в цель 20 секунд; затем выбор определяли
страницы подходящих транзакций. В v2 это автоматическое разрешение не применяется.

Общая награда уровней State 24–29 составляла 50, 25, 12,5, 6,25, 3,125 и
1,5625 NOID, минимум 1 NOID на уровнях 30–32. Расширение требовало устойчивой
заполненности 75%. Исходный срок распределения — 4 730 400 блоков, номинальный
суточный интервал — 4 320 блоков. Переход v2 сохраняет трёхлетний срок целевого
времени от genesis с учётом нового интервала; см. [экономику](../protocol/economics.md).

Исторические пределы блока: 256 физических тел, 1 020 живых пользовательских
входов, 510 выходов и 1 530 действий, до 256 затронутых сегментов. Кодек должен
читать эти старые записи. Предел кодека не является бюджетом допуска v2.

Для старого C1 расчёт давал цель FRI 128 бит, доказанные и предположительные
классические оценки Block–Tiwari FS-FRI 127 бит, границу половинного успеха
идеального QROM 64,707407428576 бит и доминирующую границу стоимости Category 1
173,391078499301 бит. Это разные величины, а не взаимозаменяемые оценки стойкости.
Расчёт происхождения v2 приведён в [модели безопасности](../protocol/security-model.md).
