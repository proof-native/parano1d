# Краткий справочник контрактов

Mainnet v2 активируется на **H210537**. Здесь описан v2; до этой высоты цепь
следует v1.1. Публичный ABI контрактов — **3**: 16 инструкций, два постоянных
u64-счётчика и два временных регистра. Все программы используют общее
доказательство блока. Small m23: 63 страницы / 504 входа / 63 вызова;
включаемый сервером Large m24: 206 / 504 / 63. Вызовы и платежи делят бюджеты.

Шесть конструкторов: платёж с возвратом, сейф, кошелёк с лимитом, бюджет за
период, регулярный платёж и освобождение траншами. Своя программа использует
то же проверяемое целочисленное ядро с явными разрешениями ветвей. Условия
фиксируют полномочия, получателей, границу, потолки комиссии и выплаты, резерв.
Депозиты независимы; запланированные переводы требуют вызовов.

**Платы за сохранение условий нет.** Пополнение — отдельный обычный платёж.
Комиссия вызова берётся из баланса контракта в пределах политики. Продолжение
создаёт преемника, закрытие переводит остаток без преемника. На высоте границы
действует возвратная ветвь.

GUI: **F7 Contracts**, затем Create, My contracts или Open file. Локальный
журнал показывает сохранённые действия обеих сторон. Импорт объединяет
проверенные данные, удаляет повторы txid и сохраняет свои записи. F4 работает
с обычными платёжными квитанциями; контракты и квитанции вызовов открываются в F7.

CLI: `parano1d-cli contract protocol`, `parano1d-cli contract --help`.
RPC использует префикс `paranoid_` и локальные права владельца. Пределы:
`getContractProtocol`, создание условий: `createObject`, пополнение:
`walletFundObject`, просмотр: `previewObjectCall`, отправка: `walletCallObject`.
Выбирайте точные slot и creation ID, привязывайте просмотренное тело перед
авторизацией. После отправки нужно подтверждение.

Храните секрет, публичные условия и квитанции. State проверяет живой баланс,
но не восстанавливает программу из обязательства. Квитанция сохраняет
доказательство прошлого вызова после очистки тела; текущую доступность
проверяют отдельно. Файл контракта содержит условия и не более одной подходящей
квитанции; дополнительные записи передавайте отдельными квитанциями.
