# Поиск

Страница «Поиск» открывает представление канонических заголовков, Live State и
недавнего окна полных данных. Нажмите `F6`.

![Представление канонической цепи](../../../assets/wallet/scope.png)

## Поиск

Поле принимает:

- адрес bech32m вида `o1…`;
- высоту блока;
- хэш блока;
- логический идентификатор транзакции;
- `slot:<index>`.

Запрос выполняет локальная полная нода. Данные не отправляются внешнему
обозревателю блоков.

## Блоки

Таблица канонических блоков показывает высоту, возраст, идентификатор блока,
уровень State и доступность данных. **Полный** отмечает 18-блочное окно
просмотра. **Заголовок** отмечает более старые записи, представленные
постоянным заголовком в этом списке.

Пока полные данные сохранены, подробности блока включают канонический
212-байтный заголовок, системные записи и пользовательские транзакции.

## Недавние транзакции

Таблица недавних транзакций строится по сохранённым полным блокам. В
подробностях видны физические страницы, входы, выходы, владельцы, комиссия и
позиция в блоке.

Старые платежи не образуют постоянную базу обозревателя блоков. Их канонические
заголовки остаются, а сохранённый чек предоставляет доказательство включения
конкретной транзакции.

## Live State

Запрос адреса возвращает его текущие UTXO. Запрос слота возвращает текущую
запись либо каноническое доказательство пустоты. Потраченные исторические
записи не восстанавливаются за пределами ограниченного окна данных отката.

Карта на главной странице и в поиске визуализирует текущую занятость, а не
историческую активность.

RPC недавних транзакций и отметка доступности GUI используют окно просмотра
18 блоков (около 9 минут при целевом темпе). Ноды хранят 42 тела для
синхронизации; этот запас обслуживания не расширяет список GUI.
